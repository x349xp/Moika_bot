# CarWash Tycoon Bot — MVP

Idle-симулятор автомойки в Telegram. Мойка работает сама (авто-очередь, авто-назначение
мойщиков), игрок только нанимает персонал, покупает оборудование и реагирует на события.
Игровой мир крутится в фоновом цикле независимо от того, открыт ли чат с ботом —
поэтому доход начисляется, даже пока игрок офлайн.

## Установка

```bash
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка

1. Получи токен бота у [@BotFather](https://t.me/BotFather)
2. Задай переменную окружения:

```bash
export BOT_TOKEN="твой_токен_сюда"
```

(На Windows: `set BOT_TOKEN=твой_токен_сюда`)

Либо просто впиши токен напрямую в `config.py` в переменную `BOT_TOKEN`.

## Запуск

```bash
python bot.py
```

База данных `carwash.db` (SQLite) создастся автоматически при первом запуске в
той же папке.

## Структура проекта

```
carwash_bot/
├── bot.py            # точка входа, фоновый игровой цикл, polling
├── config.py         # все игровые константы: цены, услуги, шансы событий
├── db.py              # схема SQLite + хелперы доступа к БД
├── game_logic.py     # ядро симуляции: очередь, авто-матчинг, доход, события
├── keyboards.py      # инлайн-клавиатуры
└── handlers/
    ├── start.py       # /start, регистрация, главное меню
    ├── station.py     # обзор мойки, список мойщиков, очередь
    ├── hire.py         # найм мойщиков
    ├── shop.py         # покупка оборудования и боксов
    └── events.py       # ремонт боксов, VIP-события
```

## Как работает игровой цикл

Каждые `TICK_INTERVAL` секунд (по умолчанию 60) фоновая задача в `bot.py` проходит
по всем зарегистрированным пользователям и для каждого:

1. Разблокирует боксы, у которых закончился ремонт.
2. С шансом (зависит от репутации) добавляет нового клиента в очередь.
3. Авто-назначает свободных мойщиков и боксы на заявки из очереди (`match_queue`).
4. Закрывает заказы, время которых истекло: начисляет оплату, катает шанс
   чаевых/жалобы, обновляет репутацию.
5. Раз в календарный день — списывает аренду, зарплаты, коммуналку и катает
   случайные события (поломка бокса, проверка санстанции, визит VIP-клиента).
6. Если что-то произошло — присылает пользователю push-уведомление.

## Что стоит доделать дальше (не входит в этот MVP)

- Настройка приоритетов очереди пользователем (сейчас — FIFO + лучший свободный мойщик)
- Прогрессия уровней мойки (локальная → сеть → франшиза)
- Таблица лидеров / соревнование агентств
- Более детальная лог-история событий (`events_log`) для аналитики баланса
- Миграции БД (Alembic) при переходе на PostgreSQL в продакшене
